# Ante Hunt Journeys

A basic mod that makes the Antediluvian hunts in Princes of Darkness possible any time before the inquisition, at the cost of going on a journey. Makes various edits to the base game events to prevent antediluvians being double hunted and to properly stop journeys so is likely incompatible with anything else that touches /common/events/POD_anarchrevolt
